# BRFSS Diabetes Machine-Learning Project

## Project overview
This repository contains the reproducible analytical workflow for an MSc research project investigating classification of reported prediabetes/diabetes status using the balanced 2015 BRFSS Diabetes Health Indicators dataset.

## Research aim
To develop and critically evaluate a reproducible and explainable machine-learning pipeline for classifying reported prediabetes/diabetes status using the balanced 2015 BRFSS health-indicators dataset.

## Models
- Logistic Regression
- Decision Tree
- Random Forest
- XGBoost

## Evaluation
Models will be compared using a common validation framework with multiple classification metrics.

## Explainability
SHAP will be used to explain the selected model.

## Subgroup evaluation
Performance will be examined across:
- Sex
- Age
- Income

## Dataset
The analysis uses the Diabetes Health Indicators Dataset derived from the 2015 Behavioral Risk Factor Surveillance System (BRFSS).

Dataset source:
https://www.kaggle.com/datasets/alexteboul/diabetes-health-indicators-dataset

The dataset itself is not included in this repository.
